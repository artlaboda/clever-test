# План тестирования десктопной версии clever.by

Пошаговый чек-лист для полной проверки десктопного сайта (`html.desk`, ширина `> 860 px`, мышь) перед выкладкой и после крупных изменений.

Автоматический прогон соответствующих пунктов лежит в [`tests/desktop.py`](desktop.py) (Python Playwright + Chromium, сеть не нужна).

## Как запускать автопроверку

```bash
# список всех пунктов без запуска браузера
python3 prototypes/app/tests/desktop.py --list

# прогнать весь десктоп (~1,5–2 минуты)
python3 prototypes/app/tests/desktop.py

# прицельно: по номеру раздела, пункту или слову в названии
python3 prototypes/app/tests/desktop.py "4."
python3 prototypes/app/tests/desktop.py "КБЖУ"
python3 prototypes/app/tests/desktop.py "5.4"
```

> **Примечание:** автопроверка идёт в Chromium. Поведение в настольном Safari (обрезка теней, `backdrop-filter`, плавность переходов) и на настоящем iPhone проверяются отдельно вручную — такие пункты помечены `[Safari]` / `[ручная]`.
